## 🎯 Project Objective

To create an interactive and functional platform that facilitates connections between companies and professionals seeking opportunities.

## 🛠 Features

- **Users**
  - Registration and login for companies and candidates.
  - User profiles with personalized information.

- **Job Management**
  - Companies can create, edit, and delete job openings.
  - Filters by location, category, and keyword.

- **Applications**
  - Candidates can apply for jobs and track the status of their applications.

- **Administrative Panel**
  - Administrators can manage users, job openings, and applications.

- **Notifications**
  - Notifications for candidates about new job openings and updates to their applications.

## 🏗 Project Structure

### 🔗 Database

The project uses a relational database with the following main tables:
- **users**: Stores user information.
- **jobs**: Contains information about job openings.
- **categories**: Classifies vacancies by category (e.g., IT, Marketing, etc.).
- **applications**: Records applications submitted by candidates.
- **job_tag**: Links vacancies with tags for additional categorization.


### 🛠 Tech Used
- **Laravel**: PHP framework.
- **MySQL**: Relational database.
- **Blade**: Template engine.
- **Bootstrap**: CSS framework for responsive design.
